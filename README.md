## BrowserOS Update and Install

This repository contains a script to download and install the latest version of BrowserOS, an AI-powered, privacy-first web browser.

### Usage

Run the installation script:

```bash
./install-browseros.sh
```

### What it does

The script will:
- Detect your system architecture (x86_64 or ARM64)
- Download the latest BrowserOS AppImage for Linux
- Make it executable
- Create a desktop entry for easy access
- Optionally launch BrowserOS

### Supported Platforms

- Linux (x86_64 and ARM64)

For other platforms:
- **macOS**: Download from https://cdn.browseros.com/releases/mac/BrowserOS-latest.dmg
- **Windows**: Download from https://cdn.browseros.com/releases/windows/BrowserOS-Setup-latest.exe

### About BrowserOS

BrowserOS is an open-source, AI-powered web browser based on Chromium that:
- Integrates AI agents for automating browsing tasks
- Supports Chrome extensions
- Prioritizes user privacy with local data storage
- Provides native support for AI assistants

Learn more at: https://github.com/browseros-ai/BrowserOS
